# Bifrost Web App

Den offentlige, statiske forside for Project Bifrost — bygget med [Next.js](https://nextjs.org) (App Router) og TypeScript.

Siden introducerer Bifrost som ét samlet gaming-økosystem med én global gaming-profil, der forbinder spillere, spil og virksomheder, og linker videre til, hvordan man kommer i gang. Der er ingen login, brugeroprettelse eller andre brugerfunktioner i denne første version.

## Kom i gang

```bash
npm install
npm run dev
```

Åbn [http://localhost:3000](http://localhost:3000) for at se siden. `src/app/page.tsx` samler sektionerne, som ligger i `src/components/`.

## Andre scripts

```bash
npm run build   # produktionsbuild
npm run start   # kør produktionsbuild lokalt
npm run lint    # eslint
```

## Design

Visuelt tema: nordisk mytologi (Bifrost som broen mellem verdener) — mørk, ceremoniel stemning med iskold blå som primær accent og bronze/kobber reserveret til logo og særlig fremhævning. Se `docs/` i roden af repoet for designinspiration.
